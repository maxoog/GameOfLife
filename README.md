# GameOfLife
My project on UIKit, completed as part of the 2020 fall Coeducation course on iOS. The project has no architecture, which in general was not required at that time of training. As part of this assignment, I worked with CATiledLayer (which is what the field of cells is based on), and also tried coding and working with a large number of UIGestureRecognizers.
